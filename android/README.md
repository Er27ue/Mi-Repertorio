# Mi Repertorio Android

El proyecto Android vive en esta carpeta. Abre esta carpeta con Android Studio y usa **Build > Build APK(s)**. El resultado se generará en `app/build/outputs/apk/debug/app-debug.apk`.

Cada compilación toma la versión actual de `../client/dist`, que se actualiza con `npm.cmd run build --workspace client` desde la raíz del proyecto.
